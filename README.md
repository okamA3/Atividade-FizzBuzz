# 🚀 Python Lógica de Programação: Fundamentos & Desafios

Este repositório reúne exercícios práticos para consolidação de conceitos essenciais de lógica de programação utilizando Python. É um excelente portfólio para demonstrar o domínio de estruturas condicionais, laços de repetição e manipulação de coleções.

## 📋 Estrutura dos Exercícios

### 1. Associação de Listas com `zip()`
Demonstra como iterar de forma paralela e elegante sobre múltiplas sequências. No exemplo, associamos elementos textuais aos seus respectivos índices numéricos:
- **Conceitos aplicados**: Coleções (listas), iteração múltipla com `zip()`, formatação de strings (f-strings).

### 2. O Clássico Desafio FizzBuzz
Uma implementação limpa e eficiente do famoso algoritmo **FizzBuzz**, muito comum em testes técnicos de programação:
- Números divisíveis por **3** geram `Fizz`.
- Números divisíveis por **5** geram `Buzz`.
- Números divisíveis por **ambos** (3 e 5) geram `Fizz Buzz`.
- Demais números são exibidos normalmente.
- **Conceitos aplicados**: Controle de fluxo (`if`, `elif`, `else`), operadores aritméticos e de módulo (`%`), geradores de intervalo (`range`).
